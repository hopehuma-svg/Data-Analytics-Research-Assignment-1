# Data-Analytics-Research-Assignment-1
This repository houses the digital workspace and foundational documentation for BrightLearn Data Analytics Research Assignment 1 (Foundations of Data Analytics & Data Science). A reader should expect a comprehensive, beginner-friendly exploration of core data systems, moving from basic data structures such as databases, warehouses, and lakes, into the mechanics of AI pipelines, machine learning, and developer frameworks like REST APIs and Git version control. Additionally, the project addresses critical ethical considerations, focusing on global compliance regulations like the GDPR, corporate data governance pillars, and algorithmic bias, all anchored by verified industry documentation and clear academic referencing.
